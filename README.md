# AI-ассистент продаж (Telegram-бот)

Тестовое задание: бот принимает обращение клиента, сверяется с короткой базой знаний
и выдаёт **два блока** — вежливый ответ клиенту + подсказку по допродажам для менеджера
(с учётом контекста диалога из AmoCRM).

Модель — локальная Ollama (`qwen2.5:3b`, docker-контейнер `simple_ollama`, `localhost:11434`).

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN
.venv/bin/python main.py
```

Проверка связи с моделью: команда `/status` в боте или

```bash
.venv/bin/python smoke_test.py
```

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Инструкция |
| `/kb` | Показать базу знаний |
| `/status` | Проверить связь с Ollama |
| `/crm ...` | Формат передачи контекста AmoCRM |

## Формат сообщения

Просто обращение клиента:

```
Сколько стоит доставка в Москве?
```

С контекстом диалога менеджера из AmoCRM (разделитель `---` на отдельной строке,
контекст — сверху, обращение клиента — снизу):

```
клиент: бюджет до 10 000, выбирает между нами и конкурентом
менеджер: доставим завтра, бесплатная от 5 000
---
а если возьму два комплекта — будет скидка?
```

Ответ бота:

```
💬 Ответ клиенту
...

🎯 Подсказка менеджеру
...

📚 Раздел БЗ: Доставка
```

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | точка входа, polling |
| `handlers.py` | команды и обработка сообщений |
| `prompts.py` | системный промпт + разбор JSON модели |
| `ollama_client.py` | клиент Ollama API (ретраи, format=json) |
| `knowledge_base.md` | демо-база знаний (заменить на реальный FAQ) |
| `config.py` | настройки из `.env` |
| `smoke_test.py` | проверка парсинга и живого вызова модели |
| `PLAN.md` | план работ |

## Замена базы знаний

Отредактируйте `knowledge_base.md` — файл целиком кладётся в системный промпт.
Перезапускать бота не нужно (`/kb` читает файл заново, промпт собирается на каждый запрос).

## Безопасность

- Токен бота хранится только в `.env` (в `.gitignore`).
- Токен, выданный ранее, считается скомпрометированным — перевыпустите его через @BotFather после тестового.
